# Licensing map of Pine Workspace

Pine Workspace is **not** distributed under a single licence. This map lists every component, where
it comes from, its licence, how it is used, whether it is shipped, the obligations taken into
account and what remains uncertain. It describes facts and choices of the copyright holder of Pine
Workspace (named in `NOTICE`); it is not legal advice.

Notes

- Source files carry an SPDX identifier, except files whose exact content is fingerprinted in kept
  evidence and are therefore left unchanged (Apache-2.0, core row): the PineTS campaign scripts and
  sources of `tools/tests/pinets_cases/` (recorded in the campaign observations) and the calibration
  case `tools/pine_exec/calibration/cases/calib-core.pine` (recorded in the calibration registry).
- A file without an SPDX identifier follows the row of the component it belongs to; when in doubt,
  `NOTICE` and this map prevail over a folder name: files of one folder do not automatically share a
  licence (for example `tools/pine_exec/` holds AGPL-3.0-only adapter files and Apache-2.0
  calibration data).
- Output produced by running the adapter (normalized payloads, run reports, calibration results)
  is data about the user's own sources and datasets; the FSF's general position is that the output
  of a program is not covered by the program's licence unless it copies substantial parts of it.
- This map is maintained with the components it describes; any change of the engine, of the way
  it is loaded or of the distributed form is checked against spec §24.4.13 before release.
